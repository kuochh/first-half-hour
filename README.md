# first-half-hour

**Does the first half-hour of trading still tell us how the day ends?**

Gao, Han, Li and Zhou (2018, *Journal of Financial Economics*) found that the S&P 500 ETF's return from the previous
close to 10:00 predicts its return over the last half-hour of the day (1993-2013). This project:

1. replicates that finding on 2011-2013 and tests it on the years after publication (2014-2026), with controls; and
2. asks a related question: given the first 30 minutes, will SPY rise a further 0.4% before the close? Can machine
   learning beat a volatility-only formula at answering it?

Status: work in progress. Results, the write-up and an interactive app will appear here.

## Data

Minute bars come from a licensed vendor and are **not** included. `data/README.md` explains how to obtain the same
data with your own key and how to check that it matches. Only derived results are published.
